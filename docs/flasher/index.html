Arixware Flasher

Install firmware

  1. Plug the arix into this computer with USB.
  2. Press the button and pick its serial port.
  3. Wait until it restarts. Do not unplug it.
Use desktop Chrome, Edge or Opera. This browser has no Web Serial. Web Serial needs HTTPS.

A USB flash erases the whole device, including saved settings and Wi-Fi.

If the port does not show up, hold BOOT while plugging in the USB cable. Later updates can install over Wi-Fi from the phone remote.
